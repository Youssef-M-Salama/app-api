# Email Notifications
> Charity-Donor Platform — V1

---

| Trigger | Recipient | Subject | Content (Arabic) |
|---------|-----------|---------|------------------|
| User registers | User | تفعيل البريد الإلكتروني — منصة وافر | Email verification link (24h expiry) |
| Email verified | User | تم تفعيل البريد الإلكتروني — منصة وافر | Account is pending admin approval |
| Admin verifies user | User | تم تفعيل الحساب — منصة وافر | Account verified, can now log in |
| Admin rejects user | User | تم رفض طلب تفعيل الحساب — منصة وافر | Account verification was rejected |
| Admin approves CharityNeed | Charity | تمت الموافقة على احتياج جمعية — منصة وافر | Charity need approved and now visible to donors |
| Admin rejects CharityNeed | Charity | تم رفض احتياج جمعية — منصة وافر | Charity need was not approved |
| Admin approves Offer | Donor | تمت الموافقة على العرض — منصة وافر | Offer approved and now visible to charities |
| Admin rejects Offer | Donor | تم رفض العرض — منصة وافر | Offer was not approved |
| Donor applies to CharityNeed | Charity | طلب جديد على احتياجكم — منصة وافر | A donor organization has applied to your charity need |
| Charity applies to Offer | Donor | طلب جديد على عرضكم — منصة وافر | A charity has applied to your offer |
| Charity accepts NeedApplication | Donor | تم قبول طلبكم — منصة وافر | Your application to the charity need has been accepted |
| Donor accepts OfferApplication | Charity | تم قبول طلبكم — منصة وافر | Your application to the offer has been accepted |
| Charity rejects NeedApplication | Donor | لم يتم قبول طلبكم — منصة وافر | Your application to the charity need was not accepted |
| Donor rejects OfferApplication | Charity | لم يتم قبول طلبكم — منصة وافر | Your application to the offer was not accepted |
